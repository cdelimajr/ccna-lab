Paano i-install sa Windows
  1. I-download ang zip, i-right-click → Extract All → Extract.
  2. I-double-click ang Setup.exe.
  3. Kung lumabas ang asul na "Windows protected your PC": More info → Run anyway.
  4. Kung Smart App Control ang humarang (walang "Run anyway"), gamitin ang Browser version sa itaas.
Paano i-install sa Android
  1. I-download ang .apk sa phone at buksan.
  2. Kapag tinanong, payagan ang Install unknown apps para sa browser o Files app.
  3. Pindutin ang Install, tapos Open.
Trainor o school?

Iisa na ang installer at Android app para sa trainee, trainor at admin. Sa unang bukas, piliin ang Trainor o Admin ako: ang unang account ang Admin at siya ang gagawa ng mga account ng trainee. May bundle para sa 10 o higit pang trainee.
