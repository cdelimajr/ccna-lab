Para sa phone o tablet (Android 7 pataas). Payagan ang "Install unknown apps" kapag tinanong.

## Paano i-install

1. I-download ang zip, i-right-click → **Extract All** → **Extract**.
2. I-double-click ang **Setup.exe**.
3. Kung lumabas ang asul na **"Windows protected your PC"**: **More info** → **Run anyway**.
4. **Next** → **Finish**. Kusang nag-a-update ang app kapag may bagong version.

## Hinarang ng Smart App Control?

Sa ilang Windows 11 PC, naka-on ang **Smart App Control** at hinaharang nito ang installer kahit walang "Run anyway". Gamitin na lang ang **browser version**: i-download ang [CCNA-Lab-200-301.html](https://github.com/cdelimajr/ccna-lab/raw/main/CCNA-Lab-200-301.html) (right-click → Save link as), tapos i-double-click para buksan sa Edge o Chrome. Pareho ang laman, gumagana kahit walang Internet, at hindi kailangang i-install.

## Galing sa Lite o Offline?

Hiwalay ang accounts at progress ng Lite/Offline sa Full app. Para ilipat sila (isang beses lang):

1. Sa lumang app: **Admin → Backup at restore** → **I-save bilang file**.
2. I-install ang Full app, buksan ang **Admin → Backup at restore** → **Buksan ang file…** → piliin ang transfer file → **I-restore**.

Idinadagdag ang mga bagong account; kapag pareho ang username, pinagsasama ang progress at walang nawawala.
